# История изменений TalkMate

Приложение сделано по спецификации из презентации ВКР (файл в корне репозитория). Код в этом репозитории написан
в октябре 2026 года. История коммитов разбита по частям проекта, а не по дням: вся работа уместилась в несколько дней.

## Сервер

- Flask, SQLAlchemy, слои контроллеров, сервисов и репозиториев, отдельный сервер анализа речи.
- Регистрация, вход, восстановление пароля по коду из письма, статьи, панель администратора с порогами оценок.
- Личный кабинет: счётчики тренировок, серия дней, темп последних записей, список тренировок.

## Анализ речи

- Темп, громкость, монотонность, слова-заполнители, чёткость, расшифровка по фразам с пометками.
- Распознавание речи: GigaAM-v3 для русского, Parakeet TDT для английского, язык записи определяется автоматически.
- Эмоции: голова поверх замороженного кодировщика WavLM, обученная на Dusha, RESD, CREMA-D, RAVDESS и MELD.
- Основная мысль и оценка структуры выступления.
- Презентация: чтение слайдов из PDF, привязка речи к слайдам по словам, смысловым векторам и отметкам приложения.

## Приложения

- Android (Kotlin) и iOS (SwiftUI): вход, запись со слайдами, результаты, статьи, статистика, личный кабинет.
- Русский и английский интерфейс с выбором языка в настройках.

## Замеры

- Сравнение восьми моделей распознавания, обучение и оценка модели эмоций на двух языках, точность привязки
  к слайдам на четырёх записях докладов. Подробности в docs/MODELS.md.
