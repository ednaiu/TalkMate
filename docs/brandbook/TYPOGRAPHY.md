# Типографика интерфейса

Обновлено 4 ноября 2026 года.

iOS: системный SF Pro, Android: системный sans-serif. Логотип Talk Mate остаётся Manrope 650. Декоративные Poiret One / Yeseva One больше не используются в заголовках экранов iOS. Тонкое начертание заменено обычным для чтения.

В iOS общий метод `Font.interface` связывает прежние размеры с нативными ролями Dynamic Type: caption, footnote, callout, body, title3, title2, title, largeTitle. Основной текст — regular, заголовки — semibold, выделенные значения — medium, главные акценты — bold. Онбординг сохраняет согласованный макет и существующие ScaledMetric; мелкий текст внутри иллюстраций не является интерфейсным текстом. Таймер сохраняет моноширинные цифры.

На экране результатов акцентный текст #4346B5 вместо #8C9EF2, пояснения #5C5C61. Цвет рамок и иллюстраций сохранён. Это решение для читаемости и согласованности, не научно доказанный способ снижать тревожность.
