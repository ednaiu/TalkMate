# Скриншоты Talk Mate

Актуальные полные наборы, по 38 экранов и состояний:

- [English: список экранов](current-ios-en/README.md) · [галерея](current-ios-en/index.html).
- [Русский: список экранов](current-ios/README.md) · [галерея](current-ios/index.html).

Кадры сняты в iPhone 17 Simulator, iOS 27.0, 1206 × 2622 px. Это нативные снимки с демонстрационными данными FakeApi/FakeRecorder, а не результаты пользовательских записей. Юридические документы показаны как проекты.

[Проверки крупного текста и компактного устройства](accessibility/) сохранены отдельно. Эти кадры относятся к отдельным проверкам и могут показывать предыдущую версию экрана; они не входят в актуальный набор.

Исходник захвата: `ios/TalkMateUITests/ScreenshotCaptureUITests.swift`. После запуска соответствующих UI-тестов передайте лог с маркерами `DOCS_SCREENSHOT:` скрипту `ios/scripts/export_screenshots.py`; для английского набора добавьте `--en`. Скрипт сохраняет PNG и индекс здесь, а скачиваемый ZIP — в игнорируемой папке `output/screens/`.

Промежуточные снимки и дубли ZIP вынесены из проекта при очистке 4 ноября 2026 года. См. [структуру репозитория](../REPOSITORY.md).
