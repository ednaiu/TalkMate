# Структура и очистка репозитория

- `android/`, `ios/`, `backend/` — приложения, сервер и тесты.
- `docs/screens/current-ios/`, `current-ios-en/` — актуальные наборы экранов RU/EN.
- `docs/brandbook/` — материалы дизайна. `TYPOGRAPHY.md` описывает текущую типографику; брендбук v1 и его генератор перенесены в архив как нереализованное предложение.
- `backend/training/` — код экспериментов и результаты. Модели, датасеты, окружение Python, база и пользовательские загрузки сохраняются локально и исключены из Git.
- `output/` — локальные артефакты. Материалы сайта-портфолио и пакеты Kaggle при очистке не изменялись.

4 ноября 2026 года промежуточные макеты, отвергнутые варианты логотипа, старые снимки и дубли ZIP перенесены в `/private/tmp/TalkMate-cleanup-20261104-182522`. В архиве есть `manifest.json` с исходными путями и размерами и состояние Git перед очисткой. Это временная локальная папка: для долгого хранения её нужно перенести в резервную копию.

Удалены только воспроизводимые результаты сборок iOS/Android и снимки браузерной автоматизации. Они создадутся при следующей сборке. История Git не переписывалась. Из iOS удалены неиспользуемые Poiret One и Yeseva One; Android продолжает использовать свои копии.
